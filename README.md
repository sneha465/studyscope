# StudyScope

An AI-powered learning platform that helps students improve their knowledge through personalized quizzes, PDF-based assessments, topic mastery tracking, and performance analytics.

## 🚀 Live Demo

https://studyscope-nu.vercel.app

---

## 📖 Overview

StudyScope combines AI-generated assessments with detailed learning analytics to create a smarter study experience.

Users can:

* Generate daily AI-powered quizzes
* Upload PDFs and generate custom quizzes from study materials
* Track learning progress over time
* Identify strong and weak topics
* Monitor quiz accuracy and performance trends
* Review previous quiz attempts with explanations

---

## ✨ Features

### 🎯 Daily AI Quiz Generation

* Generates personalized daily quizzes using AI
* Multiple-choice questions with explanations
* Balanced difficulty levels
* Tracks quiz completion history

### 📄 PDF Quiz Generator

* Upload lecture notes, research papers, study guides, or PDFs
* Extracts content directly from the uploaded document
* Generates AI-powered quizzes from study material
* Customizable number of questions
* Adjustable difficulty levels
* Instant assessment based on uploaded content

### 📊 Learning Analytics

* Knowledge Score tracking
* Weekly Accuracy monitoring
* Accuracy Trend visualization
* Quiz Completion Heatmap
* Performance-based insights

### 🧠 Topic Mastery

* Tracks topic-wise performance
* Identifies strengths
* Highlights weak areas
* Continuously updates based on quiz results

### 📝 Quiz History

* Stores Daily Quiz attempts
* Stores PDF Quiz attempts
* Review answers and explanations
* Track historical performance

### 🔐 Authentication

* Secure Google Authentication
* User-specific dashboard and analytics
* Personalized quiz history
