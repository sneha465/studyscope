# StudyScope

AI-powered daily learning and knowledge tracking platform.

## Features

- AI-generated daily quizzes
- Topic mastery tracking
- Quiz history
- Knowledge score
- Learning streaks
- Firebase authentication
- OpenRouter AI integration

## Tech Stack

- React
- Vite
- Firebase
- Firestore
- OpenRouter
- Tailwind CSS
